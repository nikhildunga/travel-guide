Travel Guide

A full-stack travel guide application that helps users explore travel destinations.

Tech Stack
Frontend

HTML

CSS

JavaScript

Backend

Node.js

Express.js

Project Structure
travel-guide/
├── Backend/
└── Frontend/

Getting Started
1. Clone the repository
git clone https://github.com/nikhildunga/travel-guide.git
cd travel-guide

2. Start the backend
cd Backend
npm install
npm start

3. Start the frontend

Open the Frontend folder and run the frontend according to the project's configuration.

Deployment

The frontend is deployed on Render.

Live application:

https://travel-guide-frontend-iogk.onrender.com/
